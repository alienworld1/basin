# Trust Basin

Basin's central boundary is split authority: the organization approves a relationship, the payee controls permitted receiving updates, and routine execution cannot bypass either in the shipped v1 path. This is not a claim that every actor or external system is trustworthy.

Read the [authority model](/trust-basin/authority-model), [evidence boundaries](/trust-basin/onchain-and-offchain-state), [stale-state semantics](/trust-basin/revocation-and-stale-state), [threat model](/trust-basin/threat-model), and [limitations](/trust-basin/privacy-and-limitations) before relying on a Basin integration.
