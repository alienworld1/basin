# Use Basin

The payer chooses who. The payee chooses where. Start in a workspace that matches your role, then follow the relationship instead of passing wallet addresses between people.

## The ordered workflow

1. A person claims a durable Basin identity and configures receiving.
2. An organization creates an **Approved Payee** relationship for that identity.
3. The payee accepts the relationship; the organization can then authorize an obligation.
4. A permitted operator executes an exact USDC payment against that obligation.
5. Basin records a receipt that can be verified against payment-time evidence.

Read [Personal workspace](/use-basin/personal-workspace) or [Organization workspace](/use-basin/organization-workspace) for the respective responsibilities.
